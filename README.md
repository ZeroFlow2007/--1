#  Fitness Club & Car Rental Management System

Консольная система управления фитнес-клубом и арендой автомобилей. Учебный проект на Java Core.

---

##  О проекте

Два независимых приложения в одном проекте:

| Система | Сущности | Основные действия |
|---------|----------|-------------------|
| **Фитнес-клуб** | Member, Membership, Visit | Вход/выход, абонементы, заморозка |
| **Аренда авто** | Client, Car, RentalEvent | Аренда/возврат, повреждения, доход |

Данные хранятся в памяти (коллекции Java).
